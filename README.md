# Vehicle Tracking and Monitoring System

An end-to-end fleet management and real-time tracking solution designed to monitor vehicle locations, optimize routes, and manage driver behavior.

---

## 🚀 Features
* **Real-Time GPS Tracking:** Live location monitoring of vehicles on an interactive map.
* **Geofencing:** Set up virtual boundaries and receive instant alerts when a vehicle enters or exits a designated zone.
* **Route History & Playback:** Review historical trip data, routes taken, and idle time.
* **Analytics Dashboard:** Visual insights into fuel consumption, vehicle health, and driver performance.
* **Alerts & Notifications:** Instant notifications for speeding, harsh braking, or unauthorized vehicle use.

## 📦 Installation & Setup
Follow these steps to get a local copy of the project up and running.

### Prerequisites
* Ensure you have [e.g., Node.js / Python 3.x / Docker] installed.
* Get an API key from [e.g., Google Maps / Mapbox].

### 1. Clone the Repository

```bash
git clone [https://github.com/Ashagiri/Vehicle-Tracking-and-Monitoring-System.git](https://github.com/Ashagiri/Vehicle-Tracking-and-Monitoring-System.git)
cd Vehicle-Tracking-and-Monitoring-System.



 2. Environment Setup
Create a .env file in the root directory and add your keys:
PORT=5000
DATABASE_URL=your_database_url
MAPS_API_KEY=your_api_key

3. Install Dependencies & Run
For Backend:
cd backend
npm install  # or pip install -r requirements.txt
npm start    # or python app.py

For Frontend:
cd frontend
npm install
npm start
